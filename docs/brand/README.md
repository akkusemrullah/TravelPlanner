# Travel Planner logo

Map pin with a paper plane cut into it — "where" and "let's go" in one mark.

| File | Use |
| --- | --- |
| `logo-mark.svg` | Mark on light backgrounds (Bright Blue pin, white plane) |
| `logo-mark-white.svg` | Mark on Royal Blue backgrounds |
| `../store/icon-source.svg` | App icon master (1024, royal blue tile) |

Wordmark: **Travel** (ExtraBold, Royal Blue) + **Planner** (Medium, Bright Blue), Plus Jakarta Sans, tight tracking.
On dark/royal blue backgrounds the whole wordmark is white.

| Colour | Hex |
| --- | --- |
| Royal Blue | `#1E3A8A` |
| Bright Blue | `#2563EB` |
| White | `#FFFFFF` |
